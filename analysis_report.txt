Отчёт по исследованию проекта SAT_DPLL
======================================
Код выданного проекта (main.cpp, BBV, BoolInterval, правила BoolEquation) не изменялся.
Найденные в нём проблемы задокументированы. Изменения внесены только в решение:
подключение Allocator и стратегии ветвления.


1. Статический анализ
---------------------
Инструмент: clang-tidy (из Qt Creator, LLVM/Clang)
Проверки:   clang-analyzer-*, bugprone-*, performance-*
Файлы:      BBV.cpp, boolinterval.cpp, boolequation.cpp, strategy.cpp

Важные предупреждения (выданный код):
- BBV.cpp:49, 106, 198 — clang-analyzer-core.uninitialized.Assign:
  запись в неинициализированную память.
- BBV.cpp:361 — clang-analyzer-core.UndefinedBinaryOperatorResult:
  сравнение с неопределённым значением.
- BBV.cpp:375 — clang-analyzer-security.ArrayBound:
  возможный выход за границу массива в куче.
- BBV.cpp:464 — bugprone-unhandled-self-assignment:
  оператор присваивания не обрабатывает самоприсваивание.

Предупреждения низкой важности:
- bugprone-narrowing-conversions: BBV.cpp:42, 97, 189; boolinterval.cpp:9, 10, 30, 31
  (сужение size_t до int).
- bugprone-easily-swappable-parameters: boolequation.cpp:10; boolinterval.cpp:53, 174.
- bugprone-throwing-static-initialization: boolequation.cpp:8, boolinterval.cpp:6
  (статические объекты из макроса IMPLEMENT_ALLOCATOR).
- bugprone-reserved-identifier, performance-enum-size: Allocator.h, DataTypes.h
  (внешняя библиотека).

В strategy.cpp собственных предупреждений нет.


2. Проблемы, найденные при чтении кода и запуске
------------------------------------------------
- BBV.cpp:100, 172, 192 — "delete vec" для памяти из "new byte[]" (должно быть delete[]).
- BBV.cpp:464 — X::operator=(X&) завершается без return (неопределённое поведение).
- BBV.h — копирование и операторы принимают неконстантную ссылку BBV&, поэтому
  временный результат операций преобразуется через operator char*(), а выделенная
  им строка не освобождается (утечка).
- BoolEquation — нет деструктора; cnf и root не освобождаются (утечка).
- main.cpp — созданные в куче узлы, уравнения и интервалы не освобождаются (утечка).
- boolinterval.cpp:69 — сравнение BBV через "!=" сравнивает указатели из operator char*().
- main.cpp — служебные строки PLA (.i, .o, .p, .type, .e) читаются как дизъюнкты:
  файлы этого формата завершаются необработанным исключением int.


3. Исправлено в решении
-----------------------
- strategy.cpp — MostConstrainedStrategy при отсутствии свободных столбцов выбрасывала
  std::out_of_range; теперь возвращает -1, как и требует контракт. Функция упрощена.
